# Entrenamiento: proteger el balón (volante central)

Rutina de 20 minutos para un volante central de 17 años: cubrir el balón con el cuerpo, media vuelta y sacar bajo presión.

## Página

Abre [index.html](index.html) o la GitHub Page del repo (cuando esté activa).

## Contenido

- Idea clave del shielding
- 3 opciones del volante (media vuelta / proteger y sacar / finta + devolución)
- Plan semanal día a día
- Videos de YouTube embebidos
- Enlaces FIFA

## Activar GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

La URL quedará en: `https://acordtolima.github.io/entrenamiento-proteger-balon/`
